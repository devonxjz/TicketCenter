TicketsCenter API

Tra cứu contract và kiểm thử các API đã triển khai.

Bắt đầu: Mở Authentication → đăng nhập bằng tài khoản kiểm thử → gọi API cần kiểm tra. Cookie phiên do trình duyệt quản lý; CSRF được lấy tự động trước mỗi thao tác thay đổi dữ liệu.

Idempotency: Nhập khóa riêng cho thao tác mới; giữ nguyên khóa và payload khi thử lại. API có nhãn “Chờ triển khai” hoặc “Legacy” chưa thể thực thi tại đây.
